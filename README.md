# Kedai Moi — Sistem Pemesanan Minuman

**Live Website:** [https://kedaimoi.netlify.app/](https://kedaimoi.netlify.app/)

## Deskripsi
**Kedai Moi** (`Project_Ordering_System`) adalah aplikasi web sistem pemesanan minuman berbasis front-end. Website ini dirancang untuk memudahkan pelanggan melihat katalog menu minuman, melakukan pemesanan secara mandiri, serta memantau status pesanan, sekaligus membantu kasir dan admin dalam mengelola antrean pesanan masuk, pembayaran, serta daftar menu.


## Fitur Utama
* **Halaman Beranda (`index.html`):** Menampilkan banner utama Kedai Moi, informasi promo minuman, serta navigasi cepat ke seluruh fitur.
* **Katalog Menu & Pemesanan (`pesan.html`):** Halaman bagi pelanggan untuk memilih menu minuman (seperti kopi susu dan es jeruk), mengatur jumlah pesanan, dan mengirim pesanan.
* **Cek Status Pesanan (`status.html`):** Halaman pelacakan bagi pelanggan untuk mengetahui apakah pesanan sedang diproses atau sudah siap diambil.
* **Manajemen Pesanan & Kasir (`pesanan.html`):** Antarmuka khusus kasir untuk menerima pesanan masuk, memproses pembayaran di kasir, dan memperbarui status pesanan.
* **Dashboard & Kelola Menu Admin (`dashboard.html`, `menu-admin.html`):** Halaman bagi admin untuk mengelola daftar menu minuman serta melihat ringkasan data penjualan.


## Cara Menjalankan (Pelanggan)

1. Buka langsung tautan berikut melalui browser di komputer maupun ponsel:
* **[https://kedaimoi.netlify.app/](https://kedaimoi.netlify.app/)**
2. Pesan makanan melaluti beberapa button pesan yang ada di bagian beranda maupun langsung di bagian menu.
3. Masukan nama anda atau nama yang memesan makanan dan juga nomor meja anda makan, anda juga bisa mengisi catatan(opsional) tambahan untuk makanan/minuman anda.
4. Konfirmasi pesanan anda dengan mengklik button kirim pe pesanan.
5. menunggu makanan anda siap dan di antar langsung ke meja anda.
6. melakukan pembayaran langsung di kasir.
catatan : anda dapat melakukan pembayaran di awal anda datang atau sementara makanan anda di proses atau setelah selesai makan.


## Cara Menjalankan (Admin)

1. Buka langsung tautan berikut melalui browser di komputer maupun ponsel:
* **[https://kedaimoi.netlify.app/](https://kedaimoi.netlify.app/)**
2. Masuk ke bagian kasir.
3. Masukan Pin Admin untuk masuk ke halaman dashboard.
4. Masuk ke halaman kelola menu untuk menambah atau menghapus menu dan juga export CSV.
5. masuk ke halaman kelola pesanan untuk mengelolah pesanan pelanggan.
6. Update status pesanan dengan mengklik kolom status.
7. centang box sudah dibayar jika pesanan sudah dibayar.
8. Update pesanan pelanggan dengan mengklik icon pensil.
9. delate pesanan dengan mengklik icon sampah
